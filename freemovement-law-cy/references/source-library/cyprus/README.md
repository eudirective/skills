## Retrieval and conversion

Rules are recorded in [source-rules.json](references/source-rules.json). For ordinary research, a human-reviewed official link is enough; record publisher, title or stable ID, language, review date, displayed edition/cutoff, relevant passage and visible caveats. Captures, hashes, conversion and replay are optional and apply only when retaining a copy or operating a recurring updater. Candidate, discovery, raw and derived files stay in the Monitor local-only archive; do not recreate pack-local candidate or capture folders. Do not bypass access challenges. If a stored capture changes, review that copy again; the external link may still be used within its verified scope.

When storing an accepted local conversion, use source-specific extraction and review only the passages, pages or attachments relied on, then place accepted source text under `documents/`. Unaccepted OCR/PDF inputs and conversions remain in the Monitor archive; do not require full-document OCR acceptance to cite a reviewed official source. The converters support replay from exact files retrieved to the standard temporary workspace. Replay demonstrates reproducibility, not legal currentness or topic completeness.

Run the inventory consistency check when changing the source register; it does not check the Monitor archive or establish legal coverage:

```sh
python3 source-library/cyprus/scripts/validate_inventory.py
```

The Cyprus `sync_candidate_pages.py ... verify` and pack-wide `convert_primary_sources.py --check` actions cannot run from this checkout because their inputs now live only in the Monitor archive; a prior candidate-page check found four HTML replay mismatches. For a targeted replay, retrieve the original and derived files with `local_research_read` and use the source-specific converter with temporary paths. The Gazette converter accepts explicit `--source-pdf`, `--ocr-pdf` and `--output` paths. Install the pinned `pypdf==6.21.1` dependency only when replaying those PDF artifacts.
