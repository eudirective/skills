# Consultation dashboard runtime assessment

## Decision

The consultation board is ordinary Markdown in the assistant's reply. It does not need an MCP tool, custom UI, or hosted service. The FreeMovement skill tells ChatGPT what to show: the review status, each required or selected operation, C27 check coverage, sources, and modules used in this answer or earlier in the chat.

## What this package can show

- Native Markdown headings and separated sections make the board easier to scan.
- Status words and optional icons distinguish reviewed, partial, not checked, unavailable, and not applicable items.
- Each partial or unavailable item names the missing evidence or operation and explains its effect.
- The module section distinguishes use in the current answer, use earlier in the chat, and relevant modules not used.
- Execution claims remain distinct from model review. A script is described as run only when the active conversation actually invoked it and its result is available.

## Limits

- The board is generated by the model from the conversation and records it has available. It is not a separate UI component and cannot add custom CSS, guaranteed colors, or interactive controls.
- A skill instruction cannot force ChatGPT to include a section, authenticate a reported source read, discover an omitted issue, or block an answer from release.
- The bundled route-receipt gate and release-binding scripts are local structural tools. They are not called automatically in ordinary ChatGPT conversations and do not execute synthetic-only case engines on real applicant facts.
- Module use and source consultation remain model-reported unless a host supplies a trusted execution or retrieval record.

## Implementation status

| Area | Status |
| --- | --- |
| Native Markdown dashboard guidance | Implemented in the core skill and examples |
| Clear status cards with missing-item/effect details | Specified for every partial, unavailable, or unrun item |
| MCP tool, custom app UI, or hosted renderer | Not part of this implementation |
| Host-enforced release gate | Not available in this package |
| Live ChatGPT rendering review | Not performed during maintenance; see the live test plan |
