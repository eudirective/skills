# Module notes bundled with eudirective-core

This directory contains source identity and scope notes for operational modules that the package registry assigns to the core package. Notes owned by a country module are shipped with that country package under its source-library references. Consult the generated national source routing registry to identify each module's package and note location.

These notes are not authoritative source texts and do not establish current law. Verify material legal and procedural claims against current official publications.
