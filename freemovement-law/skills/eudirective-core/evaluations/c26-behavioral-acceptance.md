# C26 — recorded-response acceptance rubric (not an executed test)

**Only grade verbatim, unedited replies with the installed skill version, profile and prompt captured.** An executed fixture or keyword-only match is never a pass. Compare observed content with the supplied narrative and contemporary primary sources when making legal-merits claims. Record direct response quotations and reviewer rationale for each criterion.

## Independent event coverage

- Make an event ledger from the user's actual report *before* reading the answer, preserving each distinct act (e.g. threats **and** physical contact). For each act mark `answered`, `needs_decisive_fact`, `preservation_or_evidence_only`, or `reasoned_exclusion` and explain why the response supports that result. One generic 'staff treatment' paragraph does not automatically cover both.
- Confirm the answer keeps staff misconduct and physical removal viable as independent considerations even if visa lodging was legally deficient. Check correct actors (officer vs contractor), competent complaint routes and limits.

## Authority statement fidelity

- Inspect every source passage the assistant uses to say the consulate invoked a ground. Compare that claim against the officer's exact statement, appointment/email chronology and any later official clarification; record source reference or `unavailable`. Applicant disclosures do not count as the authority invoking the issue. A later official invocation must not be backdated.
- Evaluate legally obligatory conditions to the **specific relief sought** even if uninvoked, but do not smuggle a merely hypothetical defense into the facts section of a complaint. Reject invented waiver, knowledge and improper nondisclosure advice.

## Substantive evidence acquisition (five-part check)

A GDPR recommendation passes only if it does more than name Article 15: specify (1) a plausible controller or how to identify one, (2) meaningful target personal-data categories, (3) a concrete request or next step, (4) major scope/third-party/security limitations, and (5) the distinction from preservation and from a national full-file route. Reasoned omission can pass only if the reviewer verifies the route is genuinely irrelevant or unavailable. If footage may expire, verify a **separate prompt preservation action** (record type, operator, temporal range when obtainable, no automatic freeze), not just an eventual GDPR request.

## Behavioral provenance and disposition

Use independent per-criterion `pass`, `fail`, `needs_review`, plus quotations and contemporaneous legal-source review notes. An unrun first response is `not_executed`, not a pass. If a specific material event or urgent preservation path was omitted, mark the case failed even when most other criteria pass. A categorical C25 fixture with no review flags remains `human_review_required`.

Negative-routing cases without an EU-family connection must not activate eudirective Core. Respect explicit invocation where the user is testing or auditing the skill as a skill rather than seeking general visa advice.
