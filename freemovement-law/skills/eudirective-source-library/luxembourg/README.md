# Luxembourg source candidates

This 42-record inventory spans legislation, guidance, forms, visas and missions, procedure, remedies, case law, oversight, civil status and legal aid. The capture pass retrieved 38 records and converted 35 to unaccepted Markdown review candidates. Three portal shells yielded no text; four candidate URLs returned 404. All 35 conversions and all three preserved PDF originals pass offline hash/replay verification. No source is accepted.

Legislation uses the official Casemates LegalDocML endpoint through ELI content negotiation. Direct official pages use an allowlisted HTTPS capture helper. Three PDFs are retained byte-for-byte and text-extracted with the pinned `pypdf` dependency. Changed page bodies remain staged for review. The initial generic pass remains in `references/luxembourg-capture-results.json` as historical evidence; its six replaced output hashes are explicitly marked superseded. Use the current [capture manifest](references/luxembourg-captures.json) for output hashes and replay state. Read the [candidate source list](references/source-list.md), [retrieval manifest](references/candidate-manifest.json), and [sustainability assessment](references/sustainability-assessment.md) before relying on any item.

Run `python sync_luxembourg.py sync` to refresh captures, `python sync_luxembourg.py verify` to check hashes and replay conversions offline, or `python sync_luxembourg.py convert-pdfs` to convert already captured PDFs without a network request. Install the pinned dependency from this directory's `requirements.txt` before PDF conversion/replay.
