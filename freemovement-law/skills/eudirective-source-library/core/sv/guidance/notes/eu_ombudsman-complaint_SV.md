## Lämna in klagomål till Europeiska ombudsmannen:

Europeiska ombudsmannen utreder klagomål från enskilda personer, företag och organisationer om administrativa missförhållanden vid Europeiska unionens institutioner, organ och byråer. . Ett klagomål måste lämnas in inom två år från det datum då den berörda personen fick kännedom om omständigheterna. Tidigare åtgärder: Klaganden måste först ha tagit kontakt med och försökt lösa ärendet med institutionen i fråga. För att säkerställa optimal service kommer endast klagomål som lämnas in med hjälp av onlineformuläret nedan att behandlas. Observera att klagomål som skickas via e-post inte kommer att accepteras.

## Vad är ett administrativt missförhållande?

Ett administrativt missförhållande uppstår om en institution eller ett organ underlåter att agera i enlighet med lagen eller principerna om god förvaltning eller kränker de mänskliga rättigheterna. Administrativa missförhållanden kan omfatta administrativa oriktigheter, oskälighet, diskriminering eller maktmissbruk, till exempel när det gäller handhavande av EU-medel, upphandlingar eller rekryteringspolicy. De omfattar också underlåtenhet att svara eller vägran eller onödig fördröjning när det gäller att ge tillgång till information i allmänhetens intresse.

## Vad Europeiska ombudsmannen inte kan göra

Europeiska ombudsmannen kan inte utreda klagomål mot nationella, regionala eller lokala myndigheter i medlemsstaterna, även om klagomålen gäller EU-ärenden. Ombudsmannen kan inte utreda ärenden som är föremål för rättsliga förfaranden .

## Lämna in klagomål

Riktlinjer för klagomål Klagomålet bör vara kortfattat. Om ett klagomål i undantagsfall måste överskrida det högsta tillåtna antalet ord i formuläret ska du bifoga hela klagomålet som bilaga och skriva en sammanfattning i klagomålsformuläret. Om det är flera saker som gått fel, beskriv vad det rör sig om och numrera de olika problemen. Ange argument och bevis för varje missförhållande som du anser föreligger. Ange tydligt vad du anser bör göras för att lösa varje fråga som klagomålet gäller. Lämna endast in dokument eller uppgifter som behövs för att förstå klagomålet till ombudsmannen. Lämna inte in personuppgifter om tredje parter om inte personuppgifterna behövs för att ombudsmannen ska kunna behandla klagomålet. Vårt särskilda onlineformulär gör att vi kan handlägga klagomål effektivare och snabbare. Om du inte kan använda onlineformuläret godtar ombudsmannen klagomål som lämnas in per vanlig post. Lämna in ditt klagomål per post Observera att vi inte kan hantera alla klagomål. Om du vill lämna in klagomål per post råder vi dig därför att gå igenom avsnittet med checklistan för att lämna in klagomål innan du lämnar in klagomålet. Om du inte kan lämna in ett klagomål online och önskar lämna in klagomål per post ber vi dig att fylla i formuläret och endast lämna in dokument eller uppgifter som behövs för att förstå klagomålet. Klagomålet bör vara kortfattat. Om klagomålet i undantagsfall omfattar mer än fem sidor, lägg till en kort sammanfattning i klagomålsformuläret och numrera sidorna i det bifogade klagomålet. Bifoga följande: Bevis för att du redan kontaktat EU-institutionen eller EU-organet i fråga för att få upprättelse. Detta är obligatoriskt för att klagomålet ska kunna behandlas. Annars meddelas du att vi inte kan handlägga ditt klagomål. I förekommande fall, styrkande dokument som rör beslutet eller ärendet som klagomålet avser, av vilka det framgår när du fick kännedom om omständigheterna. Se till att dokumenten som bifogas som bevis för missförhållandet (t.ex. korrespondens) är numrerade och namngivna (t.ex. 1 – Brev från xx-datum, 2 – E- post till xx-datum). Lämna också in en lista med namn och nummer på varje dokument. Ange nummer på de dokument som du hänvisar till i klagomålet. Lämna inte in personuppgifter om tredje parter om inte personuppgifterna behövs för att ombudsmannen ska kunna behandla klagomålet.
