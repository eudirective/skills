1 Specifica delle API Open Data 
1.1 Indirizzi 
L’indirizzo completo URL a cui raggiungere le varie API si ottiene giustapponendo un suffisso proprio 
di ciascuna API ai seguenti indirizzi, in funzione dell’ambiente target. Nel dettaglio:  
• Ambiente di esercizio: https://api.normattiva.it/t/normattiva.api 
• Ambiente di test (PRE): https://pre.api.normattiva.it/t/normattiva.api

1.3.3 Visualizzazione dettaglio atto tramite URN 
Suffisso URL: /bff-opendata/v1/api/v1/atto/dettaglio-atto-urn 
Descrizione: API per visualizzare il dettaglio di un atto data la sua URN, navigando per articolo. 
Sarà possibile visualizzare il contenuto testuale dell’atto legislativo o parte di esso. Se non viene 
specificato alcun articolo, viene visualizzato di default il primo articolo dell’atto. Nel caso in cui il 
risultato sia dubbio, ovvero la ricerca porti a più atti, verrà visualizzata una lista di atti. Per ulteriori 
dettagli inerenti alla codifica dell’URN fare riferimento a questa pagina Normattiva. 
 
Input previsti: 
• urn:  urn:nir:<documento>[<art>][<versione>] 
Dove: 
- <documento>::=<autorità> “:”<denominazioneAtto> “:” <estremi>  
- <estremi>::= yyyy-mm-dd;numdocumento || yyyy;numdocumento 
- <art>::= ~art<numero articolo> || :<allegato>~art<numero articolo> 
- <versione>::=@originale|!vig=yyyy-mm-dd 
 
Dove: 
 
- autorità: autorità emittente dell’atto (Es.: stato) 
- denominazioneAtto: tipo di atto (Es.: decreto.legge) 
- estremi: data e numero provvedimento (Es.: 2008-11-10;180 o 2008;180) 
- art: (opzionale) articolo (Es.: ~art2) oppure :numero_allegato ed articolo (Es.: :1~art2) 
- versione: (opzionale) @originale se si richiede la versione originale oppure !vig=yyyy-mm-dd
