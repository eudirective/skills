## Captured source text

It is almost always possible to have a foreign document legalised. This is usually done in the country where the document originates. First, select the country or region where your document was issued to find out how you can have it legalised there.

Attention: If you have a document from Aruba, Curaçao, St Maarten, Bonaire, Saba or St Eustatius, you can use it on all of these islands and in the Netherlands without having it legalised.
