# Pending Austria source updates

The monthly monitor stores changed official response bytes under `raw/` and a converted review candidate beside them. These are candidates only: compare publisher identity, current legal version, scope, links/forms, extraction quality, and reuse terms. Promote a candidate only after human review, updating the manifest and capture ledger together. Never accept or replace source content merely because a hash changed.

The monitor checks the fixed candidate manifest. It does not discover every Austrian mission, Land authority, or new case-law record. Those discovery gaps are tracked in [`../references/coverage-register.md`](../references/coverage-register.md).
