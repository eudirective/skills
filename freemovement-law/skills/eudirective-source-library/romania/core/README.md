# Romania shared EU core

This folder contains Romanian-language representations of shared EU sources only. National legislation, Romanian court decisions, and Romanian authority guidance are kept under `documents/`.

The canonical English EU corpus is in [`source-library/core/`](../../core/). The root-level [Romanian language index](../../national-language-index-RO.json) and [state file](../../national-language-state-RO.json) record representation coverage, retrieval status, and update checks. They do not establish legal completeness or trust promotion.
