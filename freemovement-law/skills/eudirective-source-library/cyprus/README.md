## Retrieval and conversion

Rules are recorded in [source-rules.json](references/source-rules.json). For ordinary research, a human-reviewed official link is enough; record publisher, title or stable ID, language, review date, displayed edition/cutoff, relevant passage and visible caveats. Local capture, hashes, conversion and replay are optional and apply only when retaining a copy or operating a recurring updater. Do not bypass access challenges. If a stored capture changes, review that copy again; the external link may still be used within its verified scope.

When storing a local conversion, use source-specific extraction and review only the passages, pages or attachments relied on. Keep original OCR/PDF files when a reproducible local copy is useful; do not require full-document OCR acceptance to cite an official source. The current converter preserves the 2007 OCR overlay, checks PDF text is substantive, and bounds Law 96(I)/2023 to its exact Act page. Replay demonstrates reproducibility, not legal currentness or topic completeness.

Run the following checks only when changing the corresponding local inventory or regenerating retained conversions; they are not prerequisites for ordinary source-link use:

```sh
python3 source-library/cyprus/scripts/validate_inventory.py
PYTHONPATH=/tmp/cyprus-tool-deps python3 source-library/sync_candidate_pages.py cyprus verify
PYTHONPATH=/tmp/cyprus-tool-deps python3 source-library/cyprus/scripts/convert_gazette_ocr.py --check
PYTHONPATH=/tmp/cyprus-tool-deps python3 source-library/cyprus/scripts/convert_primary_sources.py --check
```

Install the pinned `pypdf==6.21.1` dependency only when replaying the OCR/PDF artifacts. These commands check local inventory consistency and deterministic replay; they do not establish current law or country completeness.
