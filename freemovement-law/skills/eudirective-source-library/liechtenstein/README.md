# Liechtenstein national-source candidates

The 40-record candidate inventory covers legislation, EEA incorporation, residence and family guidance, visas, procedure, forms, remedies, courts, privacy, oversight and legal aid. The 19 October recheck saved 16 official HTML pages as Markdown review candidates and preserved two official PDFs byte-for-byte; both PDFs now also have page-wise Markdown text conversions. Two additional responses were an interactive-form initial step and a court-search application shell. Four routes point only to nonproduction staging hosts, and 16 requests returned HTTP 403. All 18 conversions pass offline replay verification. No candidate has been accepted.

[`references/liechtenstein-captures.json`](references/liechtenstein-captures.json) records source and conversion hashes, current-text-frame URLs, statuses and per-item results. [`sync_liechtenstein.py`](sync_liechtenstein.py) uses allowlisted ordinary HTTPS GET requests, current-version iframe discovery for Gesetze.li, bounded response sizes, and deterministic offline conversion replay. Run `python3 sync_liechtenstein.py convert-pdfs` to rebuild PDF Markdown from saved bytes, and `python3 sync_liechtenstein.py verify` to check source hashes and replay every HTML/PDF conversion. PDF tooling is pinned in [`requirements.txt`](requirements.txt). The workflow does not authenticate, submit forms, or bypass blocked responses. Changed sources remain staged for review.

The rule is useful for bounded capture and replay, but not ready for unattended legal-source maintenance. Gesetze.li consolidated text is informational rather than the legally authentic State Law Gazette; the current reuse and publisher conditions need reconciliation. PDF text is searchable, but signatures are not validated and layout fidelity still needs human comparison. LLV 403 responses, selected court coverage, dynamic authority guidance, mission routes and the 2026 reuse framework remain unresolved. See the [source list](references/source-list.md) and [sustainability assessment](references/sustainability-assessment.md). All outputs remain review candidates.
