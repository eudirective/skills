# Lithuania source review

The 21 October 2026 register contains 47 official source references across legislation, residence and family procedures, guidance and forms, visas and missions, administrative remedies, courts, privacy, oversight, legal aid, address declaration, resident-register data, and civil status. Thirty-six official external references are accepted within their recorded scope; 11 remain pending currentness or content review. This is link usability, not a finding that any topic is adequately covered or that Lithuania is complete.

The earlier capture saved 13 TAR API texts, two official HTML texts, and one court-search surface. All 15 local text conversions remain review candidates; no local copy or topic is accepted. The TAR API is an optional snapshot source, not a reliable current-version selector where its dates conflict with e-TAR. Prefer the government-published consolidated e-TAR version shown for the relevant date. No Gazette-chain reconstruction, local copy, conversion, hash, or scheduled updater is required for ordinary link use.
