# National source candidates

These files are local captures or conversions whose local-copy review state is recorded separately. Organize them by source type: `legislation`, `guidance`, `forms`, `case_law`, `oversight`, and `procedure`. Put indexes, search portals, discovery pages, and textless surfaces under `discovery/`.

The candidate manifest records identity, publisher, legal status, language, source URL, and any local retrieval/conversion state. A successful capture is not local-copy acceptance. A human-reviewed official link can still be used as a source within its reviewed scope without a local capture; see the shared source selection and review policy.
