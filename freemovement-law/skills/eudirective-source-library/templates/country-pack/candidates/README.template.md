# National source candidates

These files are unaccepted captures or conversions. Organize them by source type: `legislation`, `guidance`, `forms`, `case_law`, `oversight`, and `procedure`. Put indexes, search portals, discovery pages, and textless surfaces under `discovery/`.

The candidate manifest is authoritative for identity, publisher, legal status, language, source URL, retrieval/conversion state, and review status. A successful capture is not acceptance.
