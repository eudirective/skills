# MAEC embassy and consulate directory

- **Source ID:** es-38
- **Publisher:** Ministry of Foreign Affairs, European Union and Cooperation (MAEC), Spain
- **Official source:** [MAEC embassy and consulate directory](https://exteriores.gob.es/es/EmbajadasConsulados/Paginas/index.aspx)
- **Checked:** 25 October 2026
- **Version or cutoff:** Official directory search result reviewed 2026-10-25; directory entries are dynamic.
- **Local source copy:** none accepted; this is a link-only reference.

**Scope.** Official discovery directory for Spanish embassies, consulates and permanent representations by country.

**Reviewed content.** The current directory lists missions and consular offices and identifies cases where another country’s embassy is competent.

**Limits.**

- The directory is a discovery route, not mission-specific visa guidance.
- Confirm the applicant’s residence, territorial jurisdiction and any representation arrangement with the destination mission.
- No exhaustive mission review or country-specific operational coverage is claimed.
