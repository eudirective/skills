# Slovakia reviewed source notes

This directory contains 40 final independently prepared source-reference or disposition notes. The notes link to official material and record its reviewed scope, dates, limitations, and outcome; they do not reproduce source text.

Thirty-six notes identify usable official external references within stated limits. Four record a source that is not accepted for current reliance or remains pending verification. No local source text or topic coverage is accepted. See [source acceptance](../references/source-acceptance.json) and the [issue-led coverage register](../references/coverage-register.md).

The former converted candidate texts and captured inputs remain in the EU Source Update Monitor's indexed local-only archive.
