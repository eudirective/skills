# Slovakia reviewed source notes

This directory contains 40 final independently prepared source-reference or disposition notes. The legislation directory also contains four complete, dated transcriptions of official Slov-Lex HTML for Acts 71/1967, 404/2011, 365/2004 and 36/2005; Slov-Lex identifies its PDF as legally binding. The notes link to official material and record its reviewed scope, dates, limitations, and outcome; they do not reproduce source text.

Thirty-six notes identify usable official external references within stated limits. Four record a source that is not accepted for current reliance or remains pending verification. Four local statutory transcriptions are accepted; no topic coverage is accepted. See [source acceptance](../references/source-acceptance.json) and the [issue-led coverage register](../references/coverage-register.md).

The other converted candidate texts and captured inputs remain in the EU Source Update Monitor's indexed local-only archive.
