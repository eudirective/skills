# Reviewed Romanian national documents

This directory contains reviewed national-source conversions. The inventory is split by source class:

- `legislation/`: national statutes and regulations.
- `case_law/`: Romanian court decisions, including secondary reproductions clearly labeled in each record.
- `guidance/`: authority guidance and public information.
- `forms/`: official forms and petition models.
- `procedure/`: authority complaint and information-request procedures.

The main inventory is [`references/manifest.json`](../references/manifest.json), which records each document's `document_class` and country-relative `document_path`. The separate [`guidance-manifest.json`](../references/guidance-manifest.json) records the additional authority-guidance lane. Unreviewed updates remain in the configured temporary workspace until acknowledged.
