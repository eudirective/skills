# Certificate evidencing residence fiction for an EU-family applicant

## Scope

Public-service description of evidence for lawful stay while an EU-family residence application is pending.

## Maintained summary

The portal says no separate application is made: MOI issues the evidence ex officio, usually when the residence application is filed. The family relationship must be proved; MOI uses a long-stay visa sticker and may issue a new sticker if the application remains pending.
