# FreeMovement package changelog

This changelog summarizes user-visible guidance, package, and bundled source-library changes in the combined distribution. Entries identify the affected package versions; linked component indexes give the exact national-package versions where there are many. Bundled legal sources are versioned snapshots, not a guarantee of current law.
